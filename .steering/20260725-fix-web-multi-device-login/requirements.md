# 要求内容 — Web版の複数端末ログイン修正

## 背景

現行コードは1アカウントの有効セッションをWeb・iOS合算で10件に制限している。
このため、登録iPhoneや過去のブラウザセッションが上限へ影響し、新しいブラウザからログインできない。

## 要求

- Web有効セッションは1アカウント10件までとする。
- iOSセッションはWeb有効セッション数へ含めない。登録iPhone5台という別要件はデバイス登録境界で扱い、この修正では上限を混在させない。
- 同じアカウントをPCとiPhoneブラウザ等の複数ブラウザで同時利用できる。
- Web設定で有効セッションを確認し、現在以外のセッションを個別に失効できる。
- Web上限到達時は、利用者が既存セッションの解除方法を理解できる表示にする。
- Bundle ID、Cookie名、API URL、既存データ、iPhoneアプリのログイン動作を変更しない。

## 受け入れ条件

- [x] iOSセッションが10件以上存在してもWebセッションを作成できる。
- [x] 有効なWebセッションが10件なら11件目のWebログインだけを拒否する。
- [x] セッション一覧に現在の接続、クライアント種別、最終利用日時を表示する。
- [x] 現在以外のセッションをWeb設定から失効できる。
- [x] 上限到達時に汎用エラーではなく、Webセッション上限と解除方法を表示する。
- [x] 認証、API、画面、lint、型、buildの回帰確認が合格する。
