# 要求内容 — iPhone入口画面のブランド背景・配置修正

## 背景・目的

iPhoneの初回案内とサインイン画面では、透明なロゴ・キャラクターの背後に固定色のカードと枠線があり、
画面周囲と異なる白い背景に見える。入口画面の背景へ自然になじませ、Web版と同じくロゴを中央、
キャラクターを右側に添えたブランド表現へ整える。

## 変更・追加する機能の説明

- やること:
  - 初回案内のキャラクター・ロゴ領域から固定背景、角丸、枠線を外す。
  - サインインのロゴ領域から固定背景、角丸、枠線を外す。
  - サインインのワードマークと右側の指定キャラクターを1組として画面中央へ置く。
  - サインインの「おかえりなさい」を中央へ置く。
- やらないこと:
  - ロゴ・キャラクター画像の加工や配色変更。
  - 文言、Appleサインイン、認証処理、画面遷移の変更。
  - 契約・支出・見直しなどデータ中心画面へのキャラクター追加。

## ユーザーストーリー

- iPhone利用者として、入口画面のロゴとキャラクターを周囲から浮く白い面なしで自然に見たい。
- サインインする利用者として、中央に整った見出しとブランド表示から迷わずAppleサインインへ進みたい。

## 受け入れ条件

- [x] AC-1: 初回案内のキャラクター・ロゴ領域に固定背景、角丸、枠線がなく、画面背景が連続して見える。
- [x] AC-2: サインインのロゴ・キャラクター領域に固定背景、角丸、枠線がなく、画面背景が連続して見える。
- [x] AC-3: サインインのワードマークと右側の指定キャラクターが1組として利用可能幅の中央に配置され、その中心が見出しの中心と揃う。
- [x] AC-4: サインインの「おかえりなさい」が中央に配置される。
- [x] AC-5: ロゴは「MUDASK」と識別でき、キャラクターはVoiceOverの読み上げ対象外である。
- [ ] AC-6: 小さいiPhone幅と文字拡大時に画像・見出し・Appleサインインが切れたり重なったりせず、縦スクロールで到達できる。
- [x] AC-7: 認証処理、文言、画面遷移、PII・機微データの扱いに変更がない。

## 制約事項

- 実在のアカウント、契約、利用実績、資格情報を参照・使用しない。
- 指定されたAsset Catalog内のワードマークとキャラクターをそのまま使う。
- キャラクターは入口画面の装飾に限定する。
- Linux環境ではXcode build・Simulator・VoiceOver実機確認を実施できないため、静的検査結果と未確認範囲を分けて記録する。
