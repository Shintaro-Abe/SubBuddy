# 要求内容 — Web支出内訳グラフのレイアウト修正

## 背景・目的

Web版「支出の内訳」のPC表示で、月次棒グラフが本来の横並びにならず崩れている。
レスポンシブ対応で追加した表示切り替えCSSが既存のレイアウト指定を上書きしているため、
PCとモバイルの双方で意図した表示に戻す。

## 変更範囲

- やること:
  - PC表示で月次棒グラフを横並びに戻す。
  - モバイル表示では既存の縦リストを維持する。
  - PC・モバイルの表示切り替えを自動テストで確認する。
- やらないこと:
  - 集計ロジック、API、データベースの変更。
  - 画面デザインや文言の追加変更。
  - MUDASKへの名称変更箇所の再変更。

## ユーザーストーリー

- Web利用者として、支出の月次推移を画面幅に合った崩れのない表示で確認したい。

## 受け入れ条件

- [x] AC-1: PC幅では月次棒グラフが横並びのフレックスレイアウトで表示される。
- [x] AC-2: モバイル幅では棒グラフを隠し、既存の月次縦リストが表示される。
- [x] AC-3: Webのlint、型チェック、対象E2Eテストが合格する。

## 制約事項

- 実在のPII・機微データを参照せず、テストは合成データのみを使う。
- 集計値、認証、通知、iPhoneアプリには影響を与えない。
