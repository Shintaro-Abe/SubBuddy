# 設計 — Web支出内訳グラフのレイアウト修正

## 実装アプローチ

汎用の `.desktop-only` は表示・非表示だけを担当させ、PCで必要なレイアウト方式は
対象要素の `.bars` に委ねる。PC側の `.desktop-only { display: block; }` を削除し、
既定状態では非表示にしない形へ変更する。モバイルの
`.desktop-only { display: none; }` は維持する。

`display: flex !important` の追加は、汎用クラスとの競合を温存するため採用しない。

## 変更するコンポーネント

| コンポーネント / ファイル            | 変更内容                                          | 対応する受け入れ条件 |
| ------------------------------------ | ------------------------------------------------- | -------------------- |
| `apps/web/src/app/globals.css`       | PC側の汎用表示指定による上書きを解消              | AC-1, AC-2           |
| `apps/web/e2e/mobile-layout.spec.ts` | 棒グラフの算出済み `display` をPC・モバイルで検証 | AC-1, AC-2, AC-3     |
| `.audit/test-status.md`              | 品質確認の開始・結果を記録                        | AC-3                 |

## データ構造の変更

なし。

## 影響範囲の分析

- `docs/` への影響: 基本設計は変わらないため更新不要。
- 既存コード・既存機能への影響: `.desktop-only` を使うPC表示要素。現状の利用箇所を確認し、要素本来の表示方式が維持されることを検証する。
- 後方互換 / マイグレーションの要否: 不要。

## 設計上の前提

- `.desktop-only` はPCで要素固有の `display` を上書きしない。
- 画面幅1023px以下では既存どおりモバイル表示へ切り替える。
- PII・機微データは扱わない。
