# 要求内容 — Webログイン復元とブランド表示調整

## 背景・目的

Webログイン画面の横並びロゴ＋キャラクターを、変更前の縦並び構成へ戻す。
あわせて、ログイン、PCサイドバー、モバイル上部バーのブランド画像を近づけ、
現在より少し大きくして識別しやすくする。

## 変更・追加する機能の説明

- やること:
  - ログイン画面を、大きなキャラクターの下に中央ロゴを置く縦並びへ戻す。
  - PCサイドバーのロゴと右側キャラクターを拡大し、間隔を縮める。
  - モバイル上部バーのロゴと右側キャラクターを拡大し、間隔を縮める。
  - 320px以上でブランド画像と主要操作をカード・ナビ領域内に収める。
- やらないこと:
  - Appleサインイン、認証処理、文言の変更。
  - PC・モバイルのナビゲーション構造や遷移先の変更。
  - ロゴ・キャラクター画像の加工や配色変更。

## ユーザーストーリー

- Web利用者として、ログイン画面でキャラクターと中央ロゴを大きく親しみやすく見たい。
- 各ページの利用者として、ロゴとキャラクターをまとまりのあるブランド表示として認識したい。

## 受け入れ条件

- [x] AC-1: ログイン画面が、中央の大きなキャラクター、その下の中央ロゴという縦並びで表示される。
- [x] AC-2: ログイン画面はキャラクター最大180px、ロゴ最大230px、追加の縦間隔0pxを基準とする。
- [x] AC-3: PCサイドバーはロゴ148px、キャラクター44px、横間隔3pxで表示される。
- [x] AC-4: モバイル上部バーはロゴ105px、キャラクター32px、横間隔2pxで表示される。
- [x] AC-5: 320px以上で画像が領域内に収まり、横スクロールやAppleサインイン・ナビ操作との重なりがない。
- [x] AC-6: ロゴは「MUDASK」または「MUDASK ホーム」と識別でき、キャラクターは読み上げ対象外である。
- [x] AC-7: Appleサインイン、認証、ナビゲーション、文言、PII・機微データの扱いに変更がない。

## 制約事項

- 提示・承認済みの[HTMLサンプル](./brand-size-spacing-sample.html)を基準にする。
- 実在のアカウント、契約、利用実績、資格情報を参照・使用しない。
- 既存の透明画像アセットをそのまま使う。
